  <name>Task 2: Install mcp-publisher and publish to MCP Registry</name>
  <files>.mcp/server.json</files>
  <action>
    1. Install mcp-publisher via Homebrew:
       ```bash
       brew install mcp-publisher
       mcp-publisher --version
       ```
       If brew fails, fall back to: download binary from GitHub releases per the quickstart docs.

    2. Authenticate with GitHub (this will open a browser for OAuth device code flow -- user will see a prompt):
       ```bash
       mcp-publisher login github
       ```
       Follow the device code flow: visit github.com/login/device, enter the code shown in terminal.

    3. Run dry-run to validate server.json + npm package match:
       ```bash
       mcp-publisher publish --dry-run
       ```
       This validates that:
       - `.mcp/server.json` exists and matches schema
       - `mcpName` in published npm package matches `name` in server.json
       - Version fields are consistent

       If dry-run fails with version mismatch: the release script should have synced versions. If it didn't, manually update `.mcp/server.json` version fields to match `package.json` version, commit on a branch, merge, then retry.

    4. Publish:
       ```bash
       mcp-publisher publish
       ```
       Expected output: "Successfully published" with server name.

    5. Verify the listing exists:
       ```bash
       curl -s "https://registry.modelcontextprotocol.io/v0.1/servers?search=replicant-mcp" | jq '.servers[0].name'
       ```
       Expected: `"io.github.thecombatwombat/replicant-mcp"`

    **If mcp-publisher login requires user interaction (device code flow):** This is expected. The terminal will show a URL and code. The user must visit the URL and enter the code. Wait for authentication to complete before proceeding to publish.
